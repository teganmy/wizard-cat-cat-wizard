# Sprint 1 Feedback

| Suggestion | Choice | Reason |
| ---------- | ------ | ------ |
| More visibility in pop ups | Adopt | Players need to be able to figure out what they're supposed to do |
| Remove left click to shoot | Adopt | Having one shooting mode will be more intuitive | 
| Add chest opening animation| Adopt | Having an "opened" visual will make what has already been looted clearer|
| Grace period/delay before enemy spwan | Adopt | This will allow players to be more prepared so they don't die immediately|
| Add stuff to buy | Adopt | This is why the coins are there, but we hadn't gotten to it by the prototype playtest |
| Fix wall blocking mechanics | Decline (for now) | Adopting this would make combat more difficult and realistic, but it is a lower priority since it doesn't break anything |
| Slow down movement | Adopt | Having the player and enemies be slower should allow the player to have more control over the mechanics |
| Add indicators of wave number | Adopt | Indicating wave number will allow the player to know how careful they should be with their health, and make sure they are not caught off-guard by later waves |
| Enemy pot-breaking mechanic | Adopt | This is more realistic than the enemy bullets doing nothing to pots |
| Slow down bullet rate | Adopt | This will mean that the player has to be slightly more strategic with their bullet use | 
| Give more warning before enemies spawn | Adopt | This is accomplished by the wave indicator + delay |
| Add win + restart conditions | Adopt | Having something that happens when you win will give the game a more satisfying ending |
| Fix dodge | Adopt | Right now, the dodge is not very intuitive, which means it doesn't help the player avoid bullets the way it's intended to |
| Add consumable secondary effect | Adapt | We may add some secondary effects that are not consumable, but would generally like to have more attack options in the future |
| Fix the bug where players get stuck in the wall | Adopt | Players are unable to continue the game once they're stuck (not good!)| 
| Add a boss fight | Adopt | This will be a more satisfying end to the level and means the player won't lose interest from fighting enemies that are all at the same level |
| Add player upgrades | Adopt | This will help create a sense of game progression, which is good for retaining player interest | 
| More sprites | Adopt | Having a larger variety of sprites will make the rooms feel more dynamic and help to avoid the sense of playing the same level over and over |
